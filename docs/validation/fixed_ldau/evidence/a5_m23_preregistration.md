# A5.5 KS paired observables preregistration

Compare spectral and local KS states at `(U,J)=(0,0),(2,0),(4,0),(2,0.9)`
eV using identical sphere integration and output definitions. Report sphere
spin moment, d `q0` per spin, eigenvalue bounds of P, d-centre exchange
splitting, Fermi energy, `E_int`, `E_DC`, `E_Hub`, `t`, candidates a/b/c,
`F`, `T*S`, and converged residuals. Resolve whether the reported
`2.356→2.511 μB` change survives like-for-like pairing; its expected
difference is `0.155 μB` in the stated definition.

This table is descriptive and does not independently decide energy adoption.
For each pair, report the final charge residual, the full fixed-U R05
residual history, and stored numeric precision as the numerical context.
There is no additional tolerance gate because this table cannot change the
energy decision: a resolved 0.155 μB shift answers the comparison, while a
smaller or unstable shift is reported with its convergence histories. The
A5.3 candidate decision uses its separate preregistered allowance and is not
inferred from this table.

Hashes will be recorded for the source files, executable, inputs and
outputs. These states share the same frozen near-converged U=0 KS restart
snapshot and physical recipe as the A5.3 derivative experiment; the snapshot
residual is recorded, and each final state is judged using the unchanged SCF
threshold. All pairs remain pending capture.

# A5.3 supplementary smaller-step W1 response probe

Purpose: measure whether the W1 central-difference response becomes more stable at smaller spin-selective shifts, because the completed `h=0.005` versus `0.0025 Ry` comparison dominates the uncertainty in `R`. The measured coarse response is about `2.4–3 electrons/Ry`; this predicts a signed-endpoint q difference of roughly `0.003 electron` at `h=0.000625 Ry` and `0.006 electron` at `h=0.00125 Ry`. The observed `h=0.005` tight-repeat q-difference variation was about `4e-9 electron`; simple propagation suggests endpoint noise around `1e-9–1e-8 electron`, or response noise around/below `1e-5 electron/Ry`. These are scale estimates only and will be replaced by the measured fine-step repeat variation. The probe tests local-response convergence without assuming an `h^2` law. It does not change the original A5.3 primary estimate or uncertainty result, and it does not inspect candidate a/b/c energy comparisons.

For each W1 spin selector (up and down), run signed shifts at `h=0.00125` and `0.000625 Ry`, keeping the same native-KS deck, physical parameters, binary/source, immutable common RS-origin restart, and independent per-case copy. Reuse the existing `lambda=0` standard and tight cases only if their input, seed, source, and executable hashes match exactly. At the finest shift, repeat all four signed cases with `conv_thr=1e-10`; keep the same physical settings. All endpoints must meet the existing literal convergence and runtime native-KS/finite-entropy checks. A failed endpoint remains a setup/measurement failure and is not replaced by a relaxed criterion.

For each `h`, use same-state `F=ETOT+lambda*selected-spin Tr(WP)-TS`, `B_a(h)=[F_a(+h)-F_a(-h)]/(2h)-q_a(0)`, and `R_{s,a}(h)=[q_s(+h_a)-q_s(-h_a)]/(2h)`. Report all signed endpoint values and both spin columns. The supplementary fine-grid primary estimate is `h=0.000625 Ry`; its local smooth-truncation uncertainty is the absolute componentwise difference from the adjacent `h=0.00125 Ry` estimate. Add the finest-step tight-repeat difference and ordinary output-rounding allowance componentwise for B and R, using the same conservative independent-box propagation as the original preregistration. Report the full determinant/solve over that measured box, including any loss of identifiability. The original `h=0.005` and `0.0025 Ry` result and its uncertainty box remain unchanged historical evidence; also report the coarse-to-fine response trend descriptively, but do not carry the largest coarse-step difference into this fine-grid local truncation estimate. Do not infer an `h^2` scaling rule, omit any fine-grid uncertainty component, or add a conditioning cutoff. If the finer response does not stabilize or the fine-grid uncertainty box still loses identifiability, report the supplementary allowance unresolved.

The supplementary result is a sensitivity study under the already approved charge-only chain rule and independent-box propagation. Fine-grid response stability and an identifiable uncertainty set permit a supplementary allowance for lead/root review; absent stability or with a singular uncertainty box, that allowance remains unresolved.

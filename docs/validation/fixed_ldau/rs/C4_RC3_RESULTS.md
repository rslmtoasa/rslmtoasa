# C4 RC3 — RS bulk route adoption

B3 removes the backend selector from the shared local-Hubbard eligibility predicate while retaining the clean-bulk, scalar-collinear fixed-U/J guards. On an accepted RS U=2, J=0 Fe endpoint, `auto` selected local moments and included `E_Hub(P_OUT)` in the physical total. At iter 20, `candidate_b` and `physical_total_energy` were the same printed value; the accepted C1 window had Diff 1.24e-8 and d-up/d-down/moment spreads 8.43e-8/1.85e-7/1.98e-7. The no-U RS and KS physical output sets matched the frozen 8b8f7ef baseline exactly (27 and 25 files per side after the recorded runtime-log exclusions). Matched pre-B3/candidate runs preserved all physical outputs for KS auto/local, KS explicit spectral, and RS explicit spectral; `str.out` differed only in runtime `cpu_s`. The 8-case routing/restart/MPI suite passed, and independent review confirmed the endpoint and comparisons. This is route-reproduction evidence for the stated clean-bulk scope, not a new ASA derivative gate.

A wrong-seed attempt (11 steps) was quarantined, and a later accepted-seed attempt was interrupted after 19 steps; both are included in the 200-step budget. The accepted run used the C3 accepted `Fe_scf` seed and consumed 20 steps.

# GSR-01 — Implement the Lounis Goldstone sum-rule interaction independently

## Prerequisites

- LR-03 PASS.
- LR-04 PASS.
- LR-06 PASS.
- The LR-03 Lounis normalization mapping is complete.

KXC-01 should normally also be available for comparison, but this task must not
depend on its implementation internally.

## Goal

Implement the published static sum-rule construction as an independent interaction
route.

The purpose is to determine an interaction consistent with the static rotational
identity, not to rescale the direct ALSDA kernel.

## Literature contract

Use the exact LR-03 mapping of the Lounis/Costa/Muniz/Mills relation.

The literature defines an effective spin splitting from the difference of the
spin-channel potentials and derives a static identity connecting `chiKS`, that
field, and ground-state magnetization.

Do not substitute BES notation directly.

## Discretization

Derive the discrete equation in the LR-04 response representation before coding.

The continuum relation schematically becomes an equation such as

\[
\Gamma U=m
\]

only after all:

- radial measures;
- angular normalization;
- site sums;
- channel conventions

have been mapped.

Do not insert/remove a `4*pi` by numerical experimentation.

## Unknown interaction

Define clearly whether `U` is:

- a pointwise radial multiplication operator;
- an angularly diagonal radial function;
- a more general response-space object.

Follow the published approximation and LR-03 mapping exactly.

Do not silently force `U` into the same form as the direct ALSDA kernel if the
derived equation says otherwise.

## Linear solve

Use a numerically stable solve appropriate to the derived matrix.

Report:

- singular values or condition number;
- rank;
- residual of the sum-rule equation.

If the problem is rank deficient in a way not resolved by the published theory,
declare BLOCKED.

Do not add Tikhonov regularization or a pseudoinverse cutoff merely to obtain a
smooth answer.

If a pseudoinverse is mathematically required by the published construction,
derive and document its null-space treatment.

## Independence

The implementation must be built from:

- static `chiKS`;
- accepted ground-state magnetization;
- the published mapped equation.

It may compare with KXC-01 **afterward**.

It must not call KXC-01 and rescale it.

## Tests

1. analytic small discretized Gamma/U/m system;
2. one-site radial fixture;
3. multisite unequal-moment fixture;
4. exact manufactured rigid-rotation problem;
5. metric-aware residual using LR-04;
6. comparison to direct ALSDA as a diagnostic only.

## Goldstone identity

Demonstrate the static identity generated by this route.

Do not yet compute the full dynamical Dyson susceptibility as part of GSR-01.

## Implementation outcome

`source/lr_goldstone_sumrule.f90` implements the independent static route in
the canonical LR-04 representation.  It solves the active normalized `L=0`
equation `Gamma U=m_00` with `Gamma=4*pi*chiKS_00*diag(m_00)`, reports SVD
singular values/rank/condition/residual diagnostics, constructs the canonical
`K_eff=4*pi*U` interaction, and marks unresolved rank deficiency or a failed
full metric-aware Goldstone identity as `BLOCKED`.  It does not use the KXC-01
module.  The deliverable is `docs/GOLDSTONE_SUMRULE_INTERACTION.md`.

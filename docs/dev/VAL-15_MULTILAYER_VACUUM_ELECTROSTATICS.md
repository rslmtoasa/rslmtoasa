# VAL-15 — Multilayer vacuum electrostatics and Green functions

Date: 2026-08-16  
Scope: the existing three-region `A | vacuum` workflow only.

## Result

The prior large-potential result was real, but the original deck was not a
trustworthy multilayer deck. Rebuilding the mapping from the Cu(001)
`buildsurf` path exposed a second, code-side defect: on `A | vacuum`, the
upper active layers were using the vacuum type as their charge-transfer
reference. That made the active metal/vacuum difference enter the local
deviation charge and then the Madelung/alignment loop.

The fix is narrow: all active types on `A | vacuum` now reference region A,
matching the one-sided `buildsurf` surface convention. No potential clipping
was added. The existing alignment damping variable `vmix` was already
implemented but was not exposed in the `&charge` namelist; it is now exposed
so a multilayer deck can use the same controlled fixed-point damping as other
SCF quantities. The validation deck uses `vmix = 0.2`.

## Trustworthy deck and mapping

The validation first runs the existing
`example/surface/fccCu001/input.nml` with `buildsurf`, `nlay = 3`, and the
existing symbolic labels. Its generated rows are:

| buildsurf type | symbolic label | interface role |
| ---: | --- | --- |
| 1 | `Cu` | frozen region A |
| 2 | `ES` | active layer 1 (`Ac1`) |
| 3 | `Cu-S` | active layer 2 (`Ac2`) |
| 4 | `Cu-S-1` | active layer 3 (`Ac3`) |

The interface deck uses the converged parameter files shipped by that same
known-good surface example, in the load-bearing order `A`, `Vac`, `Ac1`,
`Ac2`, `Ac3`. The generated interface geometry reports
`nlay_a, nlay, nlay_b = 1, 3, 1`, `ntype, nbulk, nrec = 5, 2, 3`, and one
representative type per active layer. Its runtime mapping is
`chargetrf_type = [1, 1, 1]`: every active layer reverts to the Cu reference.
The vacuum row is the second frozen type and is generated by `vacuum_lead`;
it is not used as an active charge-transfer reference.

The synthetic Madelung stack is deliberately separate from the atomic buffer
width. With the default centered registry for 49 rows, the active rows are
24–26 and the compensation sites are the innermost frozen rows 23 and 27.
For `A | vacuum`, the boundary N(E_F) weights are `1.0 / 0.0`, so all
compensation stays on the metallic side and none is placed in vacuum.

## Diagnosis

The hand-built pre-fix three-layer deck produced, at its first interface
iteration, `step = -2.745441 Ry`, followed by nonphysical density and an
FPE. With the buildsurf-derived deck and the corrected reference mapping, the
first ten undamped production iterations stayed finite and neutral, but the
step grew from `-0.486775 Ry` to `+1.733303 Ry`. Thus the remaining failure is
not a non-neutral Madelung kernel input: `Q` is zero after compensation.
The first growing quantity is the active-layer dipole `P`/deep-probe step in
the charge → Madelung → alignment → vacuum-refresh feedback loop. Damping the
existing alignment write-back (`vmix = 0.2`) makes the same production run
finite for the guarded validation window and drives the step back toward the
one-layer scale; a longer 12-iteration production attempt still re-entered
the oscillatory mode, so full multilayer SCF convergence is not claimed here.
The vacuum-onset warning remains visible and was not suppressed.

## Validation evidence

The registered checker is
[`val15_multilayer_vacuum.py`](../../tests/validation/val15_multilayer_vacuum.py).
It checks the buildsurf provenance, symbolic/layer mapping, region/type counts,
runtime charge-transfer mapping, compensation rows and weights, finite active
layer `vmad` profile, and the active local DOS. The short damped campaign
reported:

| atomic buffer width | final step (Ry) | Q | compensation weights | active vmad (Ry) |
| ---: | ---: | ---: | --- | --- |
| 1 | -0.145498 | 0.0 | 1.0 / 0.0 | 0.100406, -0.208376, -0.240338 |
| 4 | -0.145498 | 0.0 | 1.0 / 0.0 | 0.100406, -0.208376, -0.240338 |

The buffer-step difference in this centered synthetic stack is `0.0 Ry` for
the four-iteration campaign. The local `ES` DOS contains 2010 finite points
and passes the non-negative spectral-density check. `calctype='L'` does not
separately expose a vacuum local Green function; the production active local
DOS is therefore the applicable spectral check, while `UnitVacuumLead` and
`UnitVacuumRegionWiring` cover the generated vacuum lead and its frozen-region
wiring.

The short campaign is intentionally a validation guard, not a claim of a
fully converged work function at every buffer width. The production run's
vacuum-onset margin must still be treated as a physical warning whenever the
solved vacuum shift brings the empty-lattice onset close to E_F.

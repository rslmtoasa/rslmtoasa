# LR-02 — Prove feasibility of a published ASA radial/angular response basis in RS-LMTO

## Prerequisite
LR-01 PASS.

## Nature
BLOCKER AUDIT. No chiKS implementation.

## Goal
Determine whether RS-LMTO eigenstates and/or Green functions can construct
\[
\chi^{ss'}_{LL'}(r,r';q,\omega)
\]
or an exact discretization/projection of that same spatial object.

## Fixed target
- BES-05: site × spherical harmonic × radial basis.
- EEB-02/03/04: site × angular × direct radial mesh × density channel.
- LCMM-02: radial/angular response retained before reduction.

No site-only replacement.

## Questions

### LMTO sphere wavefunction
Derive the exact RS-LMTO form inside sphere s, including:
- radial partial waves;
- energy derivatives if part of the basis;
- spinor coefficients;
- angular normalization;
- eigenvector coefficient normalization.

### Reconstructability
Prove whether actual KS spinors can be evaluated on the radial/angular grid from eigenvectors or Green functions.

### Density/spin matrix elements
Derive local operator matrix elements for charge and transverse spin without discarding radial/angular information.

### Radial representation
Do not choose Chebyshev vs direct mesh by convenience.
A direct radial mesh is allowed only if exact quadrature/mapping to existing radial data is proved and no extra physics approximation is introduced.

### Angular content
Derive the angular content generated by products of the actual basis functions.
Do not choose response lmax by speed or test fitting.

### Finite q
Derive the exact Bloch/Fourier phase and endpoint gauge in the chosen response representation.

### Backend compatibility
Assess whether eigenpair Lehmann, k-space GF, and real-space GF can populate the same response object.

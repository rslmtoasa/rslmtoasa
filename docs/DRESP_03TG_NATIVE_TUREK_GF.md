This is a focused representation audit. It treats the native Turek object as
the auxiliary/path-operator Green function used by Pajda et al.,

\[
 [g^\sigma(z)]^{-1}=P^\sigma(z)-S,
 \qquad
 J_{ij}=\frac{1}{4\pi}\operatorname{Im}\int_C dz\,
 \operatorname{Tr}_L[
 \Delta P_i g^\uparrow_{ij}
 \Delta P_j g^\downarrow_{ji}].
\]

The physical/true LMTO Green function is therefore not required for the
representation gate. The live code provides enough information to construct
a common screened representation \(P^\alpha,S^\alpha\), and hence

\[
 g^\alpha(k,z)=[P^\alpha(z)-S^\alpha(k)]^{-1}.
\]

The native path-operator algebra, direct complex solve, ordered q-space
exchange, and independent real-space Fourier closure are implemented and
pass. `source/exchange.f90` remains unchanged. Fe mesh stability is a
separate production-material question.

## 1. Primary verdict

The decisive representation chain is now identified:

| object | live source and meaning |
|---|---|
| \(P^\gamma\) | native complex p-matrix built with normalized `dele`; its matching screening is `potential%qi` |
| \(P^\alpha\) | screening transform with `screening_in=qi`, `screening_out=alpha` |
| \(S^\alpha\) | production lattice%sbar, generated by the selected structure backend with the same target alpha |
| \(g^\alpha\) | the direct inverse \([P^\alpha-S^\alpha]^{-1}\), constructed by native complex P-S solves |

For strux_lib, structb_strux stores the alpha used to generate sbar in
symbolic_atoms(:)%potential%screening_alpha; predls consumes that same array
when it builds the production tight-binding parameters. For the legacy path,
micha uses the historical LMTO47 values before its internal fak=2
normalization; those values are explicit native-constructor inputs, and the
backend comparison fixture verifies the resulting screened convention for
the supported legacy sp/spd cases.

Here `gamma_raw=qpar` is the historical pre-predls/raw screening, while
`gamma_norm=qi` is the normalized screening paired with the `dele`-based
potential used by the native evaluator. This passes the representation gate
and feeds the native q-space exchange evaluator documented in the contour
closure.

## 2. Green-function taxonomy

The following names are kept distinct.

| symbol | live object | status |
|---|---|---|
| \(G_H^\sigma(k,z)\) | inverse of zI-H(k) in the reciprocal ham_only path | existing orthogonal coefficient-space resolvent |
| \(g^{aux}_{ij}\) | green%auxiliary_gij output | endpoint-scaled H-resolvent block, \(D_iG_HD_j\) |
| \(g^{out}_{ij}\) | green%transform_auxiliary_gij output | screening transform of an auxiliary block, including its onsite additive term |
| \(g^\alpha\) | \([P^\alpha-S^\alpha]^{-1}\) | native Turek path operator constructed by direct complex P-S solves |
| \(G_{LMTO}\) | physical/true LMTO GF | not needed for this gate and remains unresolved |

auxiliary_gij is an independent H-side cross-check only. It is not used as
the definition of native \(g^\alpha\).

## 3. Audit of p_matrix

source/symbolic_atom.f90:477-506 constructs, in the live orbital ordering
l*l+m with spin-up first,

\[
 P_l^\sigma(E)=
 \frac{E-[c_l^\sigma+V_{mad}]}{(dele_l^\sigma)^2}.
\]

The production semantics are:

* potential%c(l,s) is the spin-dependent potential center;
* potential%vmad is included in the numerator;
* potential%dele(l,s) is the real endpoint-width factor;
* the denominator is dele**2, not dele; and
* the matrices are diagonal in the spherical-harmonic orbital channels.

The normalized native construction uses `potential%dele` and therefore
\(\gamma_{\rm norm,l}^\sigma=potential\%qi_l^\sigma\). The raw
\(\gamma_{\rm raw}=qpar\) values belong to the historical pre-predls
representation and must not be paired directly with this normalized P.

The complex continuation is direct:

\[
 P_l^\sigma(z)=
 \frac{z-[c_l^\sigma+V_{mad}]}{(dele_l^\sigma)^2},
 \qquad z\in\mathbb C.
\]

No new code is required for this algebra; the existing real-energy routine
can be extended pointwise by replacing the real energy with complex z.

### Relation to d_matrix

source/symbolic_atom.f90:315-341 implements

\[
 d_l(E)=
 \frac{c_l^\downarrow(dele_l^\uparrow)^2
       -c_l^\uparrow(dele_l^\downarrow)^2
       +[(dele_l^\downarrow)^2-(dele_l^\uparrow)^2]E}
      {dele_l^\uparrow dele_l^\downarrow}.
\]

Including vmad in both centers cancels in the difference, and direct
substitution gives the exact live identity

\[
 d_l(z)=dele_l^\uparrow dele_l^\downarrow
        [P_l^\uparrow(z)-P_l^\downarrow(z)].
\]

The identity is algebraic over complex z; it is not restricted to the real
energy mesh. A controlled numerical continuation using Fe potential
parameters at four complex energies gave a maximum residual of 2.64e-16.
The existing DRESP-03R fixture gives the corresponding real-energy residual
1.1102e-16 and shows that d_matrix is not raw DeltaP for unequal widths.

## 4. Audit of transform_pmatrix

source/symbolic_atom.f90:518-548 cites Turek Eq. (3.56) and implements,
channel by channel,

\[
 P^{out}=
 \frac{P^{in}}
 {1+(\alpha_{in}-\alpha_{out})P^{in}}.
\]

Equivalently,

\[
 (P^{out})^{-1}=(P^{in})^{-1}
                 +(\alpha_{in}-\alpha_{out}).
\]

Because the live P is diagonal, this is applied independently to every
(l,m,sigma) channel. The expression is rational in P, so its complex
extension is the same formula with P(z).

The meanings of the arguments are literal:

* screening_in is the l- and spin-resolved screening used by pmat_in;
* screening_out is the screening used by pmat_out; and
* the transform is from in to out, not an endpoint rescaling of an H
  resolvent.

The named production conventions are:

* potential%qi is the normalized gamma screening paired with the `dele`-based
  P matrix;
* potential%qpar is retained only as the historical raw/pre-predls screening;
* screening_can=0 in the three-index exchange auxiliary route is the live
  canonical output requested by that route; and
* qm_canonical in predls is the default target screening used when the
  structure backend has not supplied an explicit screening_alpha.

qm_lmto47 is declared in source/math.f90 but has no live production caller;
it is not used to identify the representation of sbar.

The last two are not silently identified with bare \(S^0\). A zero screening
argument in the auxiliary transform is a named canonical endpoint; the
representation of production structure constants is established separately
in Section 5.

## 5. Representation of lattice%sbar

The name sbar is not used as evidence. The producer path was traced.

### strux_lib

source/lattice_strux.f90:289-571 selects the effective screening mode:

| lattice%screening | target alpha used for production sbar |
|---|---|
| manual | lattice%screening_alpha |
| default | default_screening_alpha |
| sigma | mkalph_lmto47_from_hcr, with hcr=screening_sigma*rmt |
| fitted | mkalph_lmto47_from_fit |

The manual/default path calls strux_compute(..., alpha_in=alpha_in) and then
strux_lmto47_screening. The sigma/fitted paths obtain the generated
alpha_l_out (or returned result%alpha_l) and use it for the screening step.
source/include_codes/strux_lib/strux_lmto47_mode.f90 constructs the screened
result by forming the LMTO47 screened solve from the bare
structure-constant problem and applying the scals transform.

The resulting result%s is copied into lattice%sbar. At the same time,
structb_strux copies the exact target alpha into
symbolic_atoms(label)%potential%screening_alpha. Therefore the structure and
potential sides share the same target representation:

\[
 S^{\alpha}=\operatorname{strux}(\alpha),
 \qquad
 P^{\alpha}=T_{\gamma\to\alpha}[P^\gamma].
\]

## 6. Native path-operator construction

For a selected production state, use the target alpha returned by the
structure backend and copied into potential%screening_alpha. For legacy sbar,
use the explicit alpha_legacy values derived in Section 5; legacy does not
need a stored potential%screening_alpha because the native P construction
starts from the normalized qi representation. At complex energy z:

\[
 P^\alpha(z)=
 T_{\gamma\to\alpha}
 \left[
 \frac{z-(c^\sigma+V_{mad})}{dele^{\sigma2}}
 \right],
\]

\[
 S^\alpha(k)=
 \sum_R S^\alpha(R)e^{i k\cdot R},
 \qquad
 g^\alpha(k,z)=[P^\alpha(z)-S^\alpha(k)]^{-1}.
\]

This is enough to define the native Turek object consistently. No
physical/true-GF map is needed for the exchange contraction.

## 7. Screening transformation identity

Let

\[
 D=\alpha_{out}-\alpha_{in},\qquad
 R=I-DP^{in}.
\]

The live transform_pmatrix relation is \(P^{out}=P^{in}R^{-1}\).
The matching structure-constant transformation is

\[
 S^{out}=S^{in}(I-DS^{in})^{-1}.
\]

The path-operator identity is then

\[
 g^{out}=R_i g^{in}R_j+D_iR_i
\]

for the block form used by green%transform_auxiliary_gij; for an offsite
block the additive term is absent:

\[
 g^{out}_{ij}=R_i g^{in}_{ij}R_j,\qquad i\ne j.
\]

source/green.f90:409-473 implements this Eq. (3.57) auxiliary screening
machinery. UnitLrRsGfRepresentation passes its offsite round-trip, onsite
additive-term, and high-energy identity checks. The production-derived
complex fixture additionally applies the same covariance algebra to a
directly constructed [P-S]^-1 and verifies that the complete two-site Turek
contraction is screening invariant.

This is the required screening certification for the representation gate. It
is not a claim that the physical/true GF is known.
